# UI Capability Specification

## Purpose

本规范定义 Clash 订阅解析器（clash-sub-parser）的管理端 Web 用户界面与交互工作台规范。系统必须提供现代化、流式弹性的多视口适配布局，废除僵化的机械像素门禁，支持高效的节点台账检索、抽屉式连接属性覆写、策略组可视化编排、订阅发布向导以及完整的国际化双语支持。

## User Scenarios & Priority

### User Story 1 - 响应式节点台账检视与即时测速 (Priority: P1)
- **GIVEN** 管理员在不同尺寸屏幕（桌面宽屏、平板、移动端）访问控制台
- **WHEN** 浏览节点列表或触发单节点即时测速
- **THEN** 界面紧凑自适应排版，关键状态与操作按钮清晰可见、无溢出遮挡，并实时反馈测速动画

### User Story 2 - 节点连接参数抽屉式便捷修改 (Priority: P1)
- **GIVEN** 节点导入后需要微调端口或传输配置
- **WHEN** 管理员点击节点卡片打开详情侧边抽屉并修改保存
- **THEN** 抽屉支持表单直接输入，保存后即时反馈成功，本地草稿与状态同步更新

### User Story 3 - 发布向导与直链复制交互 (Priority: P2)
- **GIVEN** 管理员新部署了系统，发布项为 0 条
- **WHEN** 打开发布管理页面
- **THEN** 界面呈现醒目的创建引导，并在生成发布后根据导出鉴权开关动态展示免密直链或受控直链

## Requirements

### Requirement: 节点列表紧凑布局与真实视口适配 [FR-UI-01]
系统 SHALL 采用流式弹性网格与语义化布局。界面排版 MUST 依据真实视口尺寸自适应调整，坚决废除无来源的 44px 等机械像素硬编码约束，确保在 360px 至 4K 宽度的真实视口下无布局挤压、文字截断或弹窗遮挡。

#### Scenario: 窄屏视口自适应排版
- **WHEN** 在 375px 宽度的移动设备视口下访问节点列表
- **THEN** 节点卡片自动单列折叠排布，主要操作按钮均可点击且无水平滚动条溢出

### Requirement: 节点健康状态筛选与全量服务端分页联动 [FR-UI-02] [NEEDS CLARIFICATION]
系统 SHALL 支持按健康状态（healthy、degraded、unhealthy、undetermined 等）对节点进行服务端全局筛选与分页联动。当前前端 `NodesView.vue` 客户端本地过滤与 3 步翻页兜底属于已知实现缺口，后续重构将对齐全量服务端分页查询；关于批量操作时的跨页选择作用范围，系统依据用户在 Q6 中的决策落地。

#### Scenario: 切换健康过滤状态
- **WHEN** 用户点击“仅看异常节点”筛选按钮
- **THEN** 界面调用服务端分页接口精确拉取符合条件的节点列表，并在数据翻页与批量操作时提供明确的范围指示

### Requirement: 策略组抽屉式编辑工作台 [FR-UI-03]
策略组管理界面 SHALL 提供侧边抽屉式编辑面板（`PolicyEditorSheet`）。面板 MUST 支持策略组名称、类型（select、fallback、loadbalance）、直接子组引用选择及动态过滤条件配置。

#### Scenario: 抽屉内配置子策略组
- **WHEN** 用户在编辑抽屉的成员下拉菜单中选择一个子策略组
- **THEN** 界面正确呈现该子组绑定关系，并校验是否存在自引用循环

### Requirement: 订阅发布管理与复制直链向导 [FR-UI-04]
发布管理界面（`PublicationsView`）SHALL 在系统为零发布记录时展示直观的指引卡片；在已配置发布项列表中，系统 MUST 根据当前 `export_auth_enabled` 开关，动态渲染带 Token 或不带 Token 的一键复制导出直链。

#### Scenario: 免密模式下呈现纯净直链
- **WHEN** 导出开关为免密公开模式
- **THEN** 发布卡片上的快速复制链接不附带 `?token=` 参数，呈现纯净路径

### Requirement: 节点连接参数人工覆写详情抽屉 [FR-UI-05]
节点详情面板 SHALL 支持直接编辑协议连接字段（显示名称、服务器地址、端口、密钥/UUID 及 WireGuard 等高级传输参数）。用户点击保存后，前端 MUST 调用 PATCH 接口将其持久化为覆写记录。

#### Scenario: 抽屉内直接修改端口
- **WHEN** 用户在详情抽屉中将节点端口从 80 改为 443 并保存
- **THEN** 前端发送 PATCH 请求，保存成功后界面上的端口即时刷新为 443

### Requirement: 国际化双语支持 (zh-CN / en-US) [FR-UI-06]
管理前端所有视图、状态标签、提示信息及错误反馈 MUST 接入 i18n 语言包（`zh-CN.json` 与 `en-US.json`），严禁在界面代码中硬编码未翻译的中文或英文字符串。

#### Scenario: 切换语言为英文
- **WHEN** 用户在控制台右上角切换系统语言为 English
- **THEN** 页面所有导航、状态文本与操作按钮平滑切换为合规的英文表述

## Success Criteria

### Measurable Outcomes
- **[SC-UI-01]** 360px ~ 1920px 视口宽度下全局界面水平溢出（Overflow-X）发生率为 0。
- **[SC-UI-02]** 节点连接覆写保存平均交互时延低于 500ms（本地网络基准）。
- **[SC-UI-03]** 国际化测试套件静态检查 TypeScript 与缺失键报错为 0。
- **[SC-UI-04]** 零记录发布引导在冷启动场景下 100% 正常弹出并可完成向导闭环。
