# Capability: Lossless SQLite Production Data Migration

## ADDED Requirements

### Requirement: 生产 SQLite 数据 100% 无损迁移与双模式兼容
系统 SHALL 使用纯 Go SQLite 驱动（`modernc.org/sqlite`）直接读取生产数据库文件，保证对现有 7,236 个节点、8 个订阅、29 个策略组、470 条分流规则及 7,297 条历史探测记录的 100% 完整继承，且不丢失任何配置属性与敏感凭证。

#### Scenario: 迁移前后数据行数与校验和完全一致
- **WHEN** 运行迁移演练工具比对生产源库与目标库
- **THEN** 迁移工具输出比对报告，节点总数严格保持 7,236，订阅总数保持 8，历史探测记录保持 7,297，规则保持 470，且关键配置字段的 SHA-256 校验和完全匹配

### Requirement: 只读迁移演练契约与回滚保障
系统在执行正式切换前，MUST 提供 `--dry-run` 演练模式，仅在临时复制副本上执行验证，严禁对挂载的生产卷数据库发起任何非受控写入；在演练未完全通过前不得修改生产数据库文件。

#### Scenario: 演练过程中发生校验失败
- **WHEN** 迁移程序在演练副本中发现存在无法映射的废弃字段或损坏节点
- **THEN** 迁移立即中止并输出详细错误报告，退出码为非 0，且源生产数据库维持只读状态不受任何影响
