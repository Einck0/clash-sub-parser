- [x] 1.1 **Task 1.1（后端探针契约真实性收紧、Speed 完整传输计时与同 Run 同节点客户端安全复用）**（写集合：`internal/application/probe/**`, `internal/probe/profiles/**`）：
  - 在 `internal/probe/profiles/profiles.go` 与 `internal/application/probe/runner.go` 中收紧各 `ProbeKind` 的真实性评估契约，废除对所有维度无条件将 `HTTP 200/204` 视为 `ContractMatched = true` 的实现：
    1. **`baseline`**：仅当 `StatusCode == http.StatusNoContent (204)` 且响应体为空（`len(Body) == 0 && BytesRead == 0`）时判定 `ContractMatched = true` 并产出 `available`（`reason=contract_matched`）；遇到明确限制信号（HTTP `401`/`403` 或 `hasRestrictionMarker` 挑战/登录标记）产出 `restricted`（`reason=access_restricted`）；任何 `HTTP 200`（如 Captive Portal 页面或 `"OK"`）或非空 `204` 一律产出 `unknown`（`reason=contract_drift`）；
    2. **`geo`**：复用既有 `internal/probe/identity.ExtractCandidate` 校验响应体，仅当 `StatusCode == http.StatusOK (200)` 且同时解析出合法出口 IP（`net.ParseIP != nil`）与 2 位 ISO 3166-1 alpha-2 国家代码时判定为 `available`（可在 `RedactedSummary` 中记录脱敏 `country=<CC>`，严禁写入完整出口 IP）；空响应、纯文本 `"OK"`、缺失 IP 或非法国家代码一律判定为 `unknown`（`reason=contract_drift`）；
    3. **`streaming` 与 `ai`**：严禁编写未经证实的 Netflix / OpenAI 私有解锁规则，严禁照搬 `subs-check-pro v3.2.1` 的误判逻辑；在未有可证明的权威业务能力契约时，**绝不判定为 `available`**——遇到明确限制信号（HTTP `401`/`403`/`451` 或 `hasRestrictionMarker` 挑战/登录标记）判定为 `restricted`（`reason=access_restricted`），传输/DNS/超时错误判定为 `error`（`reason=transport_error`），其余响应（含首页 `200`、`204` 空响应或普通非空正文）一律保持 `ContractMatched = false` 并返回 `unknown`（`reason=contract_drift`）；
    4. **`ip_risk`**：明确区分“出口身份”与“风险评分”——使用 `identity.ExtractCandidate` 校验 `cloudflare.com/cdn-cgi/trace` 响应，若无法提取合法出口 IP + 2 位国家代码则标记 `ExitIdentityMissing = true` 并返回 `unknown`（`reason=missing_exit_identity`）；若仅提取出出口身份而无真实风险情报源（`iprisk.Provider`）验证通过的风险评估结果，保持 `ContractMatched = false` 并返回 `unknown`（`reason=contract_drift`），绝不因 `trace` 返回 `200` 而标为 `available`；
    5. **`speed`**：在 `readBoundedResponse` 完整读取响应体之后再截止计算 `latency = r.clock().Sub(reqStart).Milliseconds()` 与 `throughput_kbps = (BytesRead * 8) / latency`；定义并执行最小有效测速负载门槛 `MinValidSpeedBytes = 1024`（仅 `HTTP 200` 且 `BytesRead >= 1024` 时 `ContractMatched = true`，拒绝 `204`、空响应及 `< 1024` 字节极短伪响应并返回 `unknown` / `reason=contract_drift`）；完整保留超过 `MaxBytesPerRequest` / `MaxBytesPerRun` 时返回 `error`（`reason=speed_budget_exceeded`）的既有超限预算错误。
