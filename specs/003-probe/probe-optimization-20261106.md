## Evidence and design decisions

- `internal/application/probe/runner.go`: stage semaphores are acquired inside scheduler Execute callbacks, consuming global slots while waiting. Move stage admission before scheduler submission. A permit covers queued + running work, is returned exactly once by OnComplete, or immediately on submission failure; cancellation while waiting admits no task. Keep stage ordering, per-node session reuse, speed opt-in/body budget, callback barrier and lifecycle cleanup. Do not add per-task goroutines to hide waiting.
- `internal/probe/queue/scheduler.go:nextEligibleLocked`: manual priority pass bypasses per-run concurrency. Preserve manual front-of-own-run priority and periodic deduplication, but enforce the same dynamic per-run cap and round-robin among eligible manual runs. Explicit cap always applies; a sole run may borrow full global capacity only when config allows. Existing active tasks are not preempted. Returning permits must never happen under scheduler lock through a reentrant callback.
- `internal/probe/platform/gemini.go`: arbitrary unknown country codes fall back to raw text and yield available; 403 is labelled banned. Require recognized ISO country, official supported-country evidence rather than blacklist-complement inference, and distinguish denied access, throttling, unexpected/login redirects and missing/ambiguous markers. Positive marker means Gemini web network observation, **not account eligibility**. Preserve countries conversion API and independently test malformed/unknown/conflicting markers and response failures. Read bodies under a detector-local cap as well as existing run-wide budget; no unbounded reads or shared-client mutation.
- Google Antigravity is an independent agentic development product (official https://developers.googleblog.com/en/build-with-google-antigravity-our-new-agentic-development-platform/ retrieved HTTP 200 by investigation). Official Gemini support https://support.google.com/gemini/answer/13575153?hl=en is not Antigravity support evidence. No official anonymous product-authorization API was established. Add `CheckAntigravity(context.Context, *http.Client) domain.PlatformCapability`, one anonymous GET to `https://antigravity.google/`, no guessed backend/OAuth calls, no credentials or login automation. Validate final HTTPS origin/product-page evidence. A reachable product entry yields **unknown**, `sub_tier=reachable`, `reason=antigravity_reachable_auth_unverified`, and explicit account-qualification-unverified summary. HTTP 200 alone/redirected login/other page cannot yield available. Denial uses restricted/access-denied, never inferred geographic ban; 429/5xx/challenge/unrecognized content are unknown; network failure is error with safe typed reason; cancellation/budget exhaustion stay unknown. Bounded body read (up to 256 KiB plus one overflow sentinel); a truncated page is not positive proof.
