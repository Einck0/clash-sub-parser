## Frozen semantic contract

- `available`: positive contract for explicitly stated evidence scope. Antigravity means official anonymous product entry, NOT account/model eligibility.
- `abnormal`: endpoint/positive partial evidence exists but region conflicts or support cannot be verified. Warning, between available and unavailable, never an inferred network outage.
- `restricted`: explicit access denial, legal/geographic block, authentication challenge, or throttling. Preserve exact reason; do not call every403 a geographic ban.
- `error`: an executed detection failed (transport/timeout, unexpected status, malformed or missing required data, detector-size overflow). UI says detection failed, not universally node unreachable. Auxiliary errors cannot override baseline health.
- `skipped`: not scheduled, dependency failed, cancellation/control/budget prevents completion. Preserve executed flag and raw facts for interrupted attempts. It does not imply target unavailable.
- `unknown`: valid historical/intrinsically indeterminate evidence only; not default for known failure/control/contract-validation branches. Historical rows are not relabelled or deleted. UI explains reason, never masks old unknown as success.

Domain exports `VerdictAbnormal` and `VerdictSkipped`; both are valid ProbeVerdict strings. Existing JSON/text verdict storage needs no migration. Domain `AggregatePlatformVerdicts(map[string]PlatformCapability) (ProbeVerdict,string)` is the sole Go group semantics: empty=>skipped/no_platforms_selected; any abnormal=>abnormal/partial_or_abnormal; any available=>available/contract_matched (retain any-available selection contract); otherwise any unknown or stale=>unknown/evidence_inconclusive; any restricted=>restricted/access_restricted; any error=>error/detection_failed; all skipped=>skipped/not_executed. Missing/invalid verdict is unknown, not success. Frontend mirrors this table, not a second business variant.

`PlatformCapability` adds optional `exit_region`, `region_source`, `evidence_scope`. Region remains the service-observed ISO country. Sources are service / cdn_trace / cdn_target. Scope is network_entry / web_region / cdn_trace as applicable. These fields survive evidence JSON, repository/API read and frontend normalization. No second representation or stale signature adapters.
