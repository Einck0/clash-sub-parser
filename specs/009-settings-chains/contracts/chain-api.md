# Chain contracts (single Go data path)

## Go shared types — owner A
`domain.ProxyChainBinding` JSON fields: id string; target_type (`subscription`/`node_group`/`node`); target_id string (stable subscription/group/logical node ID); dialer_type (`node`/`node_group`); dialer_id string; enabled bool; sort_order int; note string; revision int64. No name-based second identity, target_name or dialer_ref compatibility.
`domain.ProxyChainConfig`: bindings []ProxyChainBinding, version string. Version is stable SHA256 of canonical ID-sorted persisted binding data; empty set has deterministic nonempty version.
`domain.ProxyChainRepository` methods `Get(ctx context.Context) (*ProxyChainConfig,error)` and `Replace(ctx context.Context, expectedVersion string, bindings []ProxyChainBinding) (*ProxyChainConfig,error)`. Replace reads/checks/writes whole small set in one SQLite transaction, mismatched version is domain conflict; row revision validated/incremented by application. No foreign-key cascade to volatile nodes/groups. Repo only owned binding table, never updates rules or nodes. Migration is new `000027_proxy_chain_bindings.sql` (existing26 endsDNS); no settings schema changes.

`resolver.ResolveInput.ChainBindings []domain.ProxyChainBinding`. `ResolvedNode` adds `DialerProxy string json:dialer_proxy,omitempty`, `ChainBindingID string json:chain_binding_id,omitempty`, `ChainSource string json:chain_source,omitempty` (winning target_type). `ResolvedPolicySnapshot.ChainEffects []ChainEffect json:chain_effects,omitempty`.
`resolver.ChainEffect`: binding_id, target_count int, chain_count int (winning assignments), skip_count int, overridden_count int; chain_samples []string and skip_samples []string of readable names, diagnostics []Diagnostic. Exported shared algorithm is invoked inside Resolve; no other module implements application-side expansion. Domain validation errors use `invalid_chain_binding`, `chain_reference_missing`, `chain_cycle`, `chain_all_targets_overlap` as appropriate. InputDigest includes sorted full bindings; SnapshotDigest includes effects/final assignments. No active bindings yields ordinary snapshot unaffected except explicit empty defaults.

## Persistence/application — owner B
New `proxychain.Service` owns Get, Options, Preview, Create, Update, Delete plus input provider. Actual idiomatic Go method signatures private to B; HTTP/assembly same B so not cross-package guessed. Provider is function(ctx)→(*resolver.ResolveInput,error), assigned from pubService.AssembleResolveInput in router or cmd wiring. Publication imports domain repository only, not proxychain service. Application replaces input.ChainBindings with candidate full set and calls existing resolver.Resolve for preview/validation; disabled missing references allowed. Snapshot provider failure cannot become empty successful list. Audit writes use existing repository, do not log credentials.

## Protected /api/v1/proxy-chains — owner B; UI F consumer
Standard existing `{data: ...}` success and error envelope; auth+CSRF middleware unchanged.
- `GET /`: data `{bindings: ProxyChainBinding[], version: string}`. Explicit empty list.
- `GET /options`: data `{nodes:[{id,name}], groups:[{id,name}], subscriptions:[{id,name}]}` from current eligible inventory/current group list/subscription metadata. names only display, IDs persist; no credentials/server secrets. No auto-refresh upstream. Missing saved refs retained by list independently.
- `GET /effects`: data `{version:string, effects:ChainEffect[], nodes:[{logical_id,display_name,dialer_proxy?,chain_binding_id?,chain_source?}]}` canonical current resolver result, no credential leaks. Invalid enabled config returns actionable422, not fake empty.
- `POST /preview`: request `{binding: ProxyChainBinding, config_version:string}`. New binding id may be empty; application assigns deterministic temporary ID for preview. Existing id replaces same row. Response `{version:string, effects:ChainEffect[], nodes:[same redacted fields]}`. No write. Stale config_version409; invalid422. Count shows final priority set, not merely target existence.
- `POST /`: request `{binding: ProxyChainBinding, config_version:string}`; ignore caller empty id/rev, reject caller nonempty new id as invalid or generate serverid consistently. Response `{binding:ProxyChainBinding, version:string}` 201.
- `PUT /{id}`: request `{binding:ProxyChainBinding, config_version:string, expected_revision:int}`; path ID authoritative, inconsistent ID422; one successful write increments row revision. Response `{binding,version}`200. Changing enabled is same PUT (no separate hidden patch semantics).
- `DELETE /{id}`: request `{config_version:string, expected_revision:int}`; existing row check; response `{version:string}`200. Deleting a higher-priority binding which exposes an unsafe lower binding must fail422 until repaired/disabled, no silent unsafe write.
409 includes readable conflict; UI retains all draft values and offers reload (confirm discards) or explicit rebase/keep draft after fetching newest config version+row revision, with revalidation. No blind automatic retry.

## Export — owner C + B
Mihomo snapshot nodes map final DialerProxy to yaml `dialer-proxy` for each supported protocol; field omitted when empty. Target upstream resolves current display name by stable ID. References must exist in actual snapshot groups/nodes.
B loads bindings for all publication requests, NodeSources when subscription binding needs it even if filter has no source dependency; active chains with non-Mihomo target fail domain validation unsupported_target_capability before graph stripping. C independently rejects non-Mihomo snapshot with any nonempty DialerProxy. No fake detour omission, no bypass of filtering/risk rules; no chains retains prior pure-node exports and groups need not be validated for those formats.
