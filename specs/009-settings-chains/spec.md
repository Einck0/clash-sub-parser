# Feature Specification: CSP、DNS 设置重做与链式代理恢复

**Branch**: dev（遵循既有云交付规则，不另建开发分支）
**Created**: 2026-11-03
**Status**: Production deployed and verified (2026-11-04, b9ace29)
**Input**: “现在把csp，dns，以及，链式代理的设置页面重做，其中链式代理之前重构直接丢了恢复一下”

## User Scenarios & Testing

### US1 — 恢复真实链式代理配置（P1）
用户打开链式代理设置，选择订阅、策略组或节点作为出口目标，再选择节点或策略组作为上游跳板，预览实际受影响节点，保存后重新打开及导出 Mihomo 配置保持一致；可编辑、启停、确认删除，不仅有入口。

独立验收：合成订阅含 A/B，跳板组含 A。订阅绑定至跳板组时 A 因重合跳过，B 的 dialer-proxy 指向跳板组；单节点绑定覆盖组绑定，组绑定覆盖订阅绑定，同级较小排序值、再较小 ID 优先。禁用/删除后恢复下一优先级，不改节点凭据或 routing rules。

失败验收：目标或跳板不存在、节点自指、同组自指、目标全部重合、节点与组混合环路均不能被保存为可生效配置；已有绑定因动态来源变化出现缺失或循环时导出明确失败，不能悄悄退回直连。部分重合明确展示跳过原因。更新遇真实 409 时保留草稿。

### US2 — CSP 设置按用途组织（P1）
CSP 设置明确区分服务端配置与本机显示偏好，按连接/订阅、检测、筛选、安全、外观组织，保留所有现有能力；DNS 与链式代理作为同一设置体系的相邻领域可直接到达。每个既有独立服务端设置沿用自身保存边界，不造误导性的全页保存按钮。

独立验收：修改订阅访问地址/拉取默认方式及检测设置，保存反馈、刷新回读与消费端一致；取消离开保留未保存内容，切分类不静默销毁草稿。鉴权 token 不回显服务端明文、不放 URL，不弱化认证。

### US3 — DNS 常用项直接可编辑（P1）
DNS 页面优先显示启用、主/备/引导解析、解析模式与 Fake-IP；高级域名映射/过滤支持自然 YAML 编辑而不是强迫输入 JSON。列表支持逐项操作和粘贴多行。可视与完整 YAML 共享同一草稿；未知嵌套字段完整保留，不能因表单未覆盖而删除。

独立验收：在可视模式修改 nameserver 与 listen，编辑 nameserver-policy/fallback-filter，保存→GET→重开→Clash DNS 深相等。非法映射/YAML 不推进 revision；真实 409、重载取消和离开取消保留确切输入；outer enabled=false 始终覆盖 raw enable=true，并保留原配置。

### Edge cases
- 空库提供可操作空状态而不是虚构候选；搜索和显示名不作为持久身份。
- 绑定引用的订阅/组/节点消失时保留配置，清楚标记失效；禁用失效绑定允许保存以修复，启用仍需校验。
- 快速切换目标/输入与迟到预览不得覆盖新草稿；预览失败不显示旧结果为当前生效结果。
- 不支持链语义的导出目标明确 422，不能无提示丢弃链；无启用链时四目标原有行为不变。
- 保现有 PROCESS-NAME 规则及其排序、终端 MATCH、主订阅元数据、稳定节点 ID、失败资产保留和健康语义。

## Requirements
- **FR-001** MUST 重新组织 CSP 设置，保既有服务端设置与本机偏好，提供三个设置领域清楚导航与原 /settings、/dns 可达。
- **FR-002** MUST DNS 常用项可见，列表逐项管理，高级映射使用 YAML、同一草稿、完整 17 键与未知嵌套字段无损。
- **FR-003** MUST DNS outer 启用权威、CAS/错误/离开及模式切换保草稿，预览与保存一致。
- **FR-004** MUST 链绑定持久化、CRUD、启停、优先级/排序、备注与真实展开预览；以稳定 ID 引用三类目标及两类跳板。
- **FR-005** MUST 复用实时策略组解析结果展开动态成员，应用优先级、重合跳过及完整环检；保存与导出使用同一算法。
- **FR-006** MUST Mihomo 全协议适用 dialer-proxy，snapshot/input digest 反映绑定变动；不支持目标真实报错，无链时不回归。
- **FR-007** MUST UI 有真实候选、预览计数/样本/原因、行级错误/忙态、删除确认与 409 草稿保护；空库和失效引用明确呈现。
- **FR-008** MUST 不改变现有业务数据/PROCESS-NAME 规则；本次按明确授权受控部署生产；不做真实探测/刷新、历史数据自动恢复或旧 Python 双轨兼容。
- **FR-009** MUST 代码可读、模块内聚、仅云端测试编译、同 SHA 镜像隔离验收、独立工程和 Critic 门禁。

## Key Entities
- ChainBinding：稳定目标与跳板引用、enabled、sort_order、note、revision。
- ChainEffect：每节点最终跳板、绑定来源、跳过及失效诊断；不是另一个持久化节点副本。
- DNS draft / saved revision：沿既有单轨链，客户端偏好不混入服务端配置。

## Success Criteria
- **SC-001** 三个设置领域均可经正常导航到达，桌面与移动深浅主题关键操作可见可用，无横向页面溢出。
- **SC-002** 真实链绑定创建/重开/修改/启停/删除后 Mihomo 导出与预览一致，覆盖优先级、部分重合、环路和失效引用。
- **SC-003** DNS 修改经保存/重开/导出全部字段一致，非法输入及真实 409 不丢输入或推进保存版本。
- **SC-004** 无链数据默认迁移为空且不破坏已有配置；原规则与设置回归和全量云端必需 checks 成功，成品经独立审查及实际 PNG 检视。

## Assumptions
CSP 指现有系统设置，不扩张为 Mihomo 运行控制器。链式代理历史输出为 Clash/Mihomo；本轮恢复该能力，对其他不具备该语义的编译器显式拒绝，后续增加支持另行设计。历史名称绑定不自动迁入当前数据库，不猜测旧节点身份。无实体手机授权；2026-11-04 用户明确授权本次 prelease 发布、生产备份、切换与上线核验，不构成永久自动部署权限。
